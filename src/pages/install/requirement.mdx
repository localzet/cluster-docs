# Системные требования

## PHP

- **PHP >= 8.2**

## Обязательные расширения

- `sockets` - для работы с сокетами
- `pcntl` - для управления процессами (Linux/Unix)
- `posix` - для системных функций (Linux/Unix)
- `json` - для работы с JSON

## Зависимости

### Localzet Server

Localzet Cluster требует **Localzet Server >= 4.2**

```bash
composer require localzet/server:^4.2
```

## Опциональные расширения

Для улучшения производительности рекомендуется установить одно из расширений:

- `uv` (libuv) - лучшая производительность
- `ev` (libev) - высокая производительность
- `event` (libevent) - хорошая производительность
- `swoole` - расширенные возможности асинхронности

## Проверка окружения

Выполните проверку вашего окружения:

```bash
php -m | grep -E 'sockets|pcntl|posix|json'
```

Все расширения должны быть в списке.

## Рекомендации

- **Процессор**: Современный многоядерный процессор
- **Память**: Минимум 512MB для базовой конфигурации
- **Сеть**: Стабильное сетевое соединение между компонентами кластера

## Docker

Если используете Docker, убедитесь, что контейнер имеет доступ к:
- Сетевой функциональности
- Процессам (для pcntl)
- Достаточным ресурсам
