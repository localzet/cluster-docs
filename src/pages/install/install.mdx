# Установка

Localzet Cluster устанавливается через Composer:

```bash
composer require localzet/cluster
```

## Общий секрет

Перед запуском примера задайте секрет не короче 32 байт:

```sh
export LOCALZET_CLUSTER_SECRET="$(php -r 'echo bin2hex(random_bytes(32));')"
```

Создайте общий файл `cluster-config.php`:

```php
<?php

require_once __DIR__ . '/vendor/autoload.php';

$clusterSecret = getenv('LOCALZET_CLUSTER_SECRET');
if (!is_string($clusterSecret) || strlen($clusterSecret) < 32) {
    throw new RuntimeException('LOCALZET_CLUSTER_SECRET must contain at least 32 bytes.');
}
```

На всех узлах должен быть один секрет из защищённого окружения. Не сохраняйте его в Git и не используйте шаблонные ключи. Общий секрет не шифрует транспорт; внутренние порты должны оставаться в доверенной сети. Готовые примеры текущего репозитория Cluster проверяют длину секрета при запуске.

## Требования

- PHP >= 8.2
- Localzet Server ^4.2 (ветка 4.x; совместимость с 7.x не подтверждена)
- Расширения PHP: sockets, pcntl, posix, json

## Структура проекта

После установки создайте следующие файлы для базовой настройки кластера:

- `register.php` - Регистратор сервисов
- `gateway.php` - Gateway сервер
- `business.php` - Business Worker
- `Events.php` - Обработчики событий

## Базовая настройка

### 1. Register (Регистратор)

Создайте файл `register.php`:

```php
<?php
use localzet\Cluster\Register;

require_once __DIR__ . '/cluster-config.php';

$register = new Register('text://127.0.0.1:1236');
$register->name = 'Register';
$register->secretKey = $clusterSecret;

if (!defined('GLOBAL_START')) {
    \localzet\Server::runAll();
}
```

### 2. Gateway (Шлюз)

Создайте файл `gateway.php`:

```php
<?php
use localzet\Server;
use localzet\Cluster\Gateway;

require_once __DIR__ . '/cluster-config.php';

$gateway = new Gateway("websocket://127.0.0.1:7273");
$gateway->name = 'ChatGateway';
$gateway->count = 4;
$gateway->lanIp = '127.0.0.1';
$gateway->startPort = 2800;
$gateway->pingInterval = 10;
$gateway->pingData = '{"type":"ping"}';
$gateway->registerAddress = '127.0.0.1:1236';
$gateway->secretKey = $clusterSecret;

if (!defined('GLOBAL_START')) {
    Server::runAll();
}
```

### 3. Business Worker

Создайте файл `business.php`:

```php
<?php
use localzet\Server;
use localzet\Cluster\Business;

require_once __DIR__ . '/cluster-config.php';
require_once __DIR__ . '/Events.php';

$worker = new Business();
$worker->name = 'ChatBusinessWorker';
$worker->count = 4;
$worker->registerAddress = '127.0.0.1:1236';
$worker->secretKey = $clusterSecret;
$worker->eventHandler = 'Events';

if (!defined('GLOBAL_START')) {
    Server::runAll();
}
```

### 4. Events (Обработчики событий)

Создайте файл `Events.php`:

```php
<?php
use localzet\Server;
use localzet\Cluster\Lib\Gateway;

class Events
{
    public static function onConnect($client_id)
    {
        Server::log("Client connected: $client_id");
    }

    public static function onMessage($client_id, $message)
    {
        Server::log("Message from $client_id: $message");
        // Отправка обратно клиенту
        Gateway::sendToClient($client_id, "Echo: $message");
    }

    public static function onClose($client_id)
    {
        Server::log("Client disconnected: $client_id");
    }
}
```

## Запуск кластера

Используйте файл `start.php` для запуска всех компонентов:

```php
<?php
define('GLOBAL_START', 1);

require_once __DIR__ . '/register.php';
require_once __DIR__ . '/gateway.php';
require_once __DIR__ . '/business.php';
```

Запустите:

```bash
php start.php start
```

## Проверка работы

После запуска вы должны увидеть запущенные процессы:
- Register (порт 1236)
- Gateway (порт 7273)
- Business Workers (подключаются к Gateway)

Подключитесь к WebSocket `ws://localhost:7273` для проверки соединения.
