## Localzet Cluster Documentation

Документация для Localzet Cluster - распределенной системы на базе Localzet Server.

### Запуск в режиме разработки

```bash
npm install
# или
pnpm install

npm run dev
# или
pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Сборка

```bash
npm run build
# или
pnpm build
```

### Структура

- `src/pages/` - MDX страницы документации
- `src/components/` - React компоненты
- `public/` - Статические файлы (изображения, логотипы)
